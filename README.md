# Syll for Android

Kotlin + Jetpack Compose port of the Syll (VocabFlow) iOS app. Plan: [docs/PORT_PLAN.md](docs/PORT_PLAN.md). Working notes: [CLAUDE.md](CLAUDE.md).

## Getting started

1. Android Studio (Ladybug or newer), JDK 17, Android SDK 35.
2. Open this folder. If `gradlew` is missing, run `gradle wrapper --gradle-version 8.11.1` once and commit the result.
3. Run the backend locally (`../backend`) on port 3000 and start the `app` configuration on an emulator.

Status: Phase 0 (foundation). See the plan for what each phase delivers.
